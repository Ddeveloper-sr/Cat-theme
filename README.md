# Mochi Catgirl Theme

A soft, dark Discord theme based on the catgirl artwork used in this repository.

![Support Scott](support-scott.jpg)

## Features

- Soft pink and rose accent colors
- Dark plum and brown interface
- Custom catgirl background
- Transparent main chat background
- Semi-transparent Discord panels
- GitHub-hosted background image
- Designed for Discord clients that support custom themes

## Installation

### Theme URL

```text
https://raw.githubusercontent.com/Ddeveloper-sr/Cat-theme/main/mochi_catgirl_theme.json
```

### Manual Installation

Download `mochi_catgirl_theme.json` from this repository and import it through your Discord client's custom theme settings.
